Input → Process → Output → Improve

A home lab run like a production line.

Every process turns inputs into outputs. Kaizen means measuring that transformation and making it a little better, every day. This site shows Kaizen Lab the way a plant floor board would: what goes in, what comes out, and the numbers in between.

  1. Input

    What goes in

    Power, bandwidth, hardware, photos, prompts and ideas.

  2. Process

    What runs

    Two virtualisation hosts and a GPU node running self-hosted services.

  3. Output

    What comes out

    Backups, uptime, AI renders and 3D-printed fixes, measured.

  4. Improve

    What we learn

    Every failure becomes a PDCA cycle: symptom, hypothesis, test, countermeasure.
